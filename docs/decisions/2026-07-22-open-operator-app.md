# 各社アプリへの誘導（予約・ライドは公式アプリ）

日付: 2026-07-22

## 決定

貸出できそうなポートでは **「{社名}で乗る」** で公式アプリ / サイトへ遷移する。
予約・解錠・決済は自前実装しない。

## Why

- 法務・決済・車両管理は各社の領域
- うちの価値は横断一覧と需要シグナル。乗る行為は公式へパスするハブ
- 買収ストーリーでも「各社のフロントを奪わない」方が協調しやすい

## いまの限界

- ポート単位の公式ディープリンクは未公開が多い → 一旦アプリ / 公式 Web + 地図で場所
- 公式連携が取れたら `buildOperatorLaunchUrl` をポート ID 付きに差し替え

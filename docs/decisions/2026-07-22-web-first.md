# Web（Next.js）先行、Flutter は後追い候補

日付: 2026-07-22

## 決定

MVP は **Next.js Web** で切る。Flutter は却下せず、ネイティブ GPS / オフラインが痛くなったら再検討。

## Why

- `toilet-map` / `paymap` と同型（地図・ローカル情報・高速フィードバック）
- TestFlight なしで URL 共有できる
- データソースが未確定のうちは UI と近傍ロジックだけ先に固める価値が高い

## Why not Flutter first

- ヌリミチ（`ride-area-battle`）と並行すると配布・署名コストが二重
- 本プロダクトの核心は「3アプリを開かない横断一覧」で、ネイティブ必須ではない

# fukuoka-share-ports（プロダクト名未定）

福岡市限定。**チャリチャリ / LUUP / ラクすく**の近くのポートと、貸出できそうかをまとめて見るアプリ。

いまは **Next.js Web**（モバイルブラウザ想定）。名前はまだない。

## いまの状態

- デモシードで天神起点の近傍ソート一覧
- 事業者フィルタの型・距離計算・テストあり
- リアルタイム満空は未接続（公式連携待ち）

## 開発

```bash
cd ~/development/projects/fukuoka-share-ports
pnpm install
pnpm dev
pnpm check
```

## スコープ（当面）

| やる | やらない |
|---|---|
| 福岡市 | 全国 |
| 近くのポート一覧 + 空きの見え方 | 予約・決済・走行 |
| 3事業者を横断 | 公式アプリの代替 |

## データ方針

本番の満空は **公式 API / 提携 / 公開データ** のみ。スクレイピングはしない。

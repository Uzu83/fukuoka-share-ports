# fukuoka-share-ports（プロダクト名未定）

**チャリチャリ / LUUP / ラクすく**などの近くのポートと、貸出できそうかをまとめて見るアプリ。

最初期の検証エリアは **福岡**。全国（多都市）展開を想定し、福岡永久限定ではない。  
いまは **Next.js Web**（モバイルブラウザ想定）。名前はまだない。

## いまの状態

- デモシードで天神起点の近傍ソート一覧（福岡）
- 「これ乗るわ😎」/「ここから乗りたかった😭」（任意で目的地）→ 端末に記録
- 乗れるポートは **各社アプリで乗る**（予約・解錠は公式アプリ）
- お気に入り +「使えるヤツ来たら通知」設定（配信は満空 live 後）
- 事業者フィルタの型・距離計算・テストあり
- リアルタイム満空は未接続（公式連携待ち）

## 開発

```bash
cd ~/development/projects/fukuoka-share-ports
pnpm install
pnpm dev
pnpm check
```

## スコープ

| フェーズ | 内容 |
|---|---|
| 最初期 | 福岡で一覧・近傍・空きの見え方を固める |
| 次 | 都市追加・事業者アダプタ本接続 |
| やらない（当面） | 予約・決済・走行・非公式スクレイピング |

## データ方針

本番の満空は **公式 API / 提携 / 公開データ** のみ。スクレイピングはしない。
